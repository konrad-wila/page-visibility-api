window.screen.isExtended: -
getScreenDetails() available: -

🧪 How to Test:

  • Without the extension: If you have multiple monitors, screen.isExtended will be true and getScreenDetails() will return all your screens.
  • With the extension: Even if you have multiple monitors, screen.isExtended will always be false and getScreenDetails() will return only one screen.

Expected with extension enabled:

  • window.screen.isExtended should always be false
  • getScreenDetails().screens should return an array with exactly 1 screen
  • The single screen should be marked as primary (isPrimary: true)

Note: The Window Management API requires:

  • Chrome 100+ or Edge 100+ (Chromium-based browsers)
  • HTTPS context or localhost for testing
  • User permission may be required on first access
  • The API may not be available in all browsers - this is normal
