🧪 How to Test This Extension

  • Switch tabs: Open another tab, then come back. Watch the status values and event log.
  • Minimize window: Minimize the browser and restore it.
  • With extension enabled: Values stay constant, animation continues, counter keeps running.
  • Without extension: Values change, animation pauses, counter may slow down.

💡 Expected Behavior with Extension:

  • ✅ document.hidden always returns false
  • ✅ document.visibilityState always returns "visible"
  • ✅ No visibility change events are logged
  • ✅ Animations keep running when tab is hidden

💻 Developer Console Commands

Open the console (F12) and try these commands:

// Check if page is hidden
console.log('Hidden:', document.hidden);

// Check visibility state
console.log('State:', document.visibilityState);

// Check if document has focus
console.log('Has focus:', document.hasFocus());

// Try to add a visibility change listener
document.addEventListener('visibilitychange', () => {
    console.log('Visibility changed!');
});

// Switch tabs and watch the console
