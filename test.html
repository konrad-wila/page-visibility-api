📄 Page Visibility API Test

document.hidden: -
document.visibilityState: -

🧪 How to Test:

  • Without the extension: Switch to another tab or minimize the window. The values will change to show the page is hidden, and blur/focus events will be logged.
  • With the extension: Switch to another tab or minimize the window. The values will remain unchanged, always showing the page as visible, and no blur/focus events will be logged.

Expected with extension enabled:

  • document.hidden should always be false
  • document.visibilityState should always be "visible"
  • document.hasFocus() should always be true
  • No "visibility changed" events should be logged
  • No window "blur" or "focus" events should be logged
